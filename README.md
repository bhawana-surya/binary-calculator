# Binary Calculator — Computer Organization Mini Project

A frontend-only binary calculator built with HTML, CSS, and JavaScript.

## Features
- Binary addition, subtraction, multiplication, and division
- Bitwise AND, OR, XOR, and NOT
- Displays results in binary, decimal, and hexadecimal
- Input validation and division-by-zero handling
- Calculation explanation
- Responsive layout
- Clear button

## How to run
1. Extract `BinaryCalculator.zip`.
2. Open the `BinaryCalculator` folder.
3. Double-click `index.html` to open it in a browser.
   - Optional: open the folder in Visual Studio Code and use Live Server.

## Input
Enter binary digits only: `0` and `1`.

Example:
- First number: `1010`
- Operation: Addition
- Second number: `1100`
- Result: `10110` (binary), `22` (decimal), `16` (hexadecimal)

## Notes
- Division uses integer division and displays the remainder.
- Subtraction can produce a negative result.
- NOT is applied within the bit width of the input number.
